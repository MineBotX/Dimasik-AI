# Dimasik License Manager

Отдельная Windows-программа для офлайн-выпуска подписанных лицензий. Firebase и VPS не используются.

## Запуск

1. Установи Python 3.10+.
2. Выполни `py -m pip install cryptography`.
3. Из корня репозитория запусти `py tools/license_manager.py`.
4. При первом запуске программа создаст Ed25519-ключи в `%APPDATA%\\DimasikLicenseManager`. Закрытый `signing_key.pem` хранится только на компьютере администратора. Не отправляй его пользователям и не добавляй в Git.
5. Нажми «Экспорт публичного ключа». Публичный ключ предназначен для встраивания в `assistant/licensing.py` вместо `PASTE_OWNER_PUBLIC_KEY_PEM_HERE`.

## Выпуск

Введи имя пользователя, тариф, срок (7, 30, 90, 180, 365 дней или 0 для бессрочной лицензии) и Device ID пользователя. Сохрани `.dimalic` и передай его пользователю.

Device ID пользователь может получить локально командой:

```bat
py -c "from assistant.licensing import device_id; print(device_id())"
```

## Перенос

Пользователь формирует запрос переноса `.dimareq` с помощью `create_transfer_request()` из `assistant.licensing`, отправляет его администратору. Администратор импортирует запрос в License Manager. Программа проверяет лицензию в своей локальной базе и запрещает повторный перенос ранее чем через 7 суток, затем выпускает новый подписанный файл для нового Device ID.

Пример создания запроса:

```python
from assistant.licensing import create_transfer_request
create_transfer_request('license.dimalic', 'transfer.dimareq')
```

## Важные ограничения офлайн-режима

- Нет центрального сервера: отзыв лицензии в базе администратора не может мгновенно отключить уже выданный файл у пользователя. Для применения отзыва нужно передать клиенту обновлённый статус/заменяющую лицензию.
- Лимит переноса в 7 дней обеспечивается базой License Manager на компьютере администратора. Он действует, когда все запросы переноса проходят через эту программу; полностью автономный клиент не может самостоятельно проверить глобальную историю переносов.
- Проверка срока на клиенте зависит от системных часов компьютера. Для защиты от ручного перевода часов требуется онлайн-проверка времени, которой в режиме без сервера нет.
- Подпись Ed25519 защищает содержимое лицензии от незаметного редактирования. В клиент встраивается только публичный ключ; закрытый ключ остаётся у администратора.

## Текущий статус интеграции

`assistant/licensing.py` содержит функции проверки подписи, срока, Device ID и создания запроса переноса. Чтобы реально ограничить функции Димасика по тарифам, приложение должно вызывать `verify_license()` при запуске и проверять `payload['plan']` перед доступом к платным функциям. До встраивания публичного ключа и подключения проверки в интерфейсе подписки не активируются автоматически.
