# Димасик — локальный голосовой помощник для Windows

## Установка
1. Открой [страницу последней сборки](https://github.com/MineBotX/Dimasik-AI/releases/tag/latest).
2. Скачай архив **Dimasik-Windows-GUI-x64.zip** и распакуй его полностью в отдельную папку.
3. Запусти **Install-Dimasik.bat** двойным щелчком.
4. Дождись установки Ollama и загрузки модели **qwen2.5:3b**. Установщик создаст ярлык «Димасик» и запустит помощника.

Python вручную устанавливать не нужно. Интернет нужен при первой установке. Ollama и Qwen занимают несколько гигабайт диска; после установки ответы ИИ работают локально. Если winget недоступен, установи Ollama вручную с https://ollama.com/download/windows и повтори запуск установщика.

## Обновление
Используй кнопку «Проверить обновления» в приложении. Обновление заменяет файлы программы, но сохраняет пользовательский config.json.

## Команды
- «Димасик, сколько времени?» / «какая дата?»
- «Открой блокнот / калькулятор / проводник / Paint / диспетчер задач».
- «Открой загрузки / документы / рабочий стол / изображения / музыку / видео».
- «Открой YouTube / Google / почту / диск / GitHub».
- «Громче», «тише», «выключи звук».
- «Открой настройки Windows», «параметры экрана», «параметры звука».
- «Заблокируй компьютер».
- «Найди ...», «помощь», «очисти диалог».

## Кастомизация
Файл настроек находится рядом с Dimasik.exe как config.json. Его можно открыть кнопкой настроек в приложении. Поддерживаются имя помощника, ключевые слова, скорость и громкость речи, характер ответов, модель Ollama, список приложений и сайтов. После изменения перезапусти помощника.

## Требования и ограничения
- Windows 10/11 x64, микрофон и динамики.
- Рекомендуется 8 ГБ ОЗУ или больше.
- Мужской голос зависит от голосов, установленных в Windows.
- Помощник не исполняет произвольные команды PowerShell и не удаляет файлы.
- Это локальная начальная версия, а не полный аналог киношного JARVIS.
