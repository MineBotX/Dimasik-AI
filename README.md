# Димасик — локальный голосовой помощник для Windows

Димасик — стартовая офлайн-версия голосового помощника. Для распознавания речи используется Vosk, для локальных ответов — Ollama с Qwen 2.5 3B, для озвучивания — системный голос Windows через pyttsx3.

## Установка

1. Откройте Install_Dimasik.bat и скачайте его через Raw → Save link as.
2. Запустите файл двойным щелчком.
3. Дождитесь загрузки компонентов и моделей.
4. Запустите ярлык «Димасик» на рабочем столе.

Нужны Windows 10/11, микрофон и интернет во время установки. После загрузки моделей распознавание речи и ответы ИИ работают локально. Для комфортной работы модели 3B желательно иметь от 8 ГБ оперативной памяти.

## Возможности первой версии

- Активация по слову «Димасик».
- Русское офлайн-распознавание речи.
- Ответы локальной модели Ollama.
- Озвучивание ответов системным голосом Windows.
- Команды: время, дата, открыть Блокнот, Калькулятор, Проводник, Paint.
- Поиск в интернете по команде «Димасик, найди ...».

## Важно

Это первая безопасная версия, а не полный аналог киношного JARVIS. Она не выполняет произвольные команды PowerShell, не удаляет файлы и не управляет настройками Windows по свободному запросу. Мужской тембр зависит от установленных голосов Windows: если доступен только женский русский голос, добавьте другой русский голос в настройках Windows.
