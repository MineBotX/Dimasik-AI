# Димасик — офлайн голосовой помощник Windows

## Возможности
- Голосовая активация «Димасик».
- Офлайн-распознавание Vosk и локальная модель Qwen через Ollama.
- Контекст диалога в пределах текущего запуска.
- Открытие программ, папок, сайтов и разделов настроек Windows.
- Громкость: «громче», «тише», «выключи звук».
- Блокировка ПК: «заблокируй компьютер».
- Дата, время, поиск в браузере, помощь.
- Настраиваемые имя, ключевые слова, голосовая скорость, громкость TTS, характер, модель, сайты и приложения.

## Установка
Скачай `Install_Dimasik.bat` из репозитория и запусти на Windows 10/11. Во время установки нужен интернет. После загрузки моделей обработка речи и ИИ-ответы выполняются локально. Рекомендуется от 8 ГБ ОЗУ.

## Кастомизация
Открой `config.json` в папке установки (обычно `%LOCALAPPDATA%\Dimasik\config.json`) в Блокноте. Измени значения и перезапусти Димасика.

Пример:
- `assistant_name`: имя помощника.
- `wake_words`: список слов активации.
- `voice_rate`: скорость речи от 100 до 250.
- `voice_volume`: громкость речи от 0.0 до 1.0.
- `personality`: стиль общения локальной модели.
- `ollama_model`: имя уже скачанной модели Ollama.
- `apps`: пользовательские команды запуска приложений. Значение — массив аргументов, например `["C:\\Tools\\app.exe"]`.
- `websites`: команды открытия сайтов. Значения должны быть URL с http:// или https://.
- `search_url`: поисковый шаблон с обязательным `{query}`.

После изменения config.json перезапусти помощника. Не указывай в конфиге команды удаления, форматирования дисков или другие опасные команды. Для приложений используй массив аргументов, а не shell-команды.

## Голос и безопасность
Русский голос выбирается из установленных голосов Windows; мужской тембр зависит от доступных голосов ОС. Помощник не выполняет произвольные PowerShell-команды, не удаляет файлы и не выключает/перезагружает ПК голосом.
