# Димасик — собственный локальный голосовой помощник для Windows

Димасик использует собственное экспериментальное нейросетевое ядро, написанное для этого проекта. В этой версии нет Qwen, Ollama, облачных ИИ API или обязательного подключения к интернету для ответов.

## Установка готовой версии
1. Открой [последнюю сборку](https://github.com/MineBotX/Dimasik-AI/releases/tag/latest).
2. Скачай и полностью распакуй архив **Dimasik-Windows-GUI-x64.zip**.
3. Запусти **Install-Dimasik.bat**.
4. Установщик создаст ярлык «Димасик» и запустит программу.

Python вручную устанавливать не нужно. Интернет нужен для скачивания архива. Русская модель распознавания речи Vosk уже входит в комплект.

## Собственная нейросеть и обучение
Модель небольшая и экспериментальная: это собственная нейронная сеть для предсказания следующего слова, а не аналог ChatGPT. Её ответы на старте ограничены размером обучающего текста.

Для обучения из исходного кода:
1. Установи Python 3.12.
2. Запусти setup.ps1 — он создаст окружение, установит зависимости, загрузит Vosk и обучит ядро.
3. Добавляй свои примеры на русском в training_data.txt (каждая строка — отдельный текст).
4. Запусти `python train_brain.py`, чтобы переобучить модель.
5. Запусти Димасика снова.

## Возможности
- Голосовое управление через Vosk и озвучивание через голоса Windows.
- Открытие программ, папок и сайтов.
- Управление громкостью, открытие настроек Windows, блокировка компьютера.
- Собственное локальное нейросетевое ядро и файл обучающих примеров.
- Проверка обновлений приложения.

## Важно
Это первый технический прототип собственного ИИ. Он пока не умеет рассуждать и программировать на уровне больших языковых моделей. Для заметного улучшения нужны большой качественный обучающий набор, эксперименты с архитектурой и тестирование. Приложение и нейросеть работают локально.
