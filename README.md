# Димасик — локальный ИИ-помощник для Windows

**Димасик (DimasikAI)** — настольный голосовой и текстовый помощник. Он работает на компьютере пользователя и объединяет голосовое управление, локальную языковую модель, поиск в интернете и повседневные инструменты.

## Возможности

- Голосовое управление на русском языке: распознавание речи через Vosk и озвучивание ответов.
- Общение текстом и голосом через графический интерфейс.
- Локальная модель **IBM Granite 4.2 3B** для диалога, анализа документов и генерации кода.
- Экспериментальное компактное ядро **DimaCore 2.0**.
- Поиск в интернете и локальная история диалогов.
- Анализ TXT, PDF, DOCX, XLSX, PPTX, JSON, CSV и других текстовых файлов.
- Создание изображений локально с помощью Stable Diffusion.
- Заметки, задачи, напоминания и калькулятор.
- Голосовые команды для запуска программ, открытия сайтов и управления Windows.
- Необязательные интеграции с GitHub и электронной почтой.

## API для своих задач

В приложении есть **API-генератор**. Опишите, для чего нужен API, и Димасик с помощью локальной Granite подготовит системный промт под эту задачу. Промт сохраняется в профиле и применяется к каждому запросу API.

API совместим с форматом OpenAI:
- `GET /health`
- `GET /v1/models`
- `POST /v1/chat/completions`

По умолчанию сервер работает только на `http://127.0.0.1:8787` и требует ключ доступа для запросов к модели. Ключ показывается при создании один раз. Не публикуйте его и не встраивайте в клиентский код.

Инструкция и примеры запросов: [API.md](API.md).

## Установка

### Готовая версия Windows

1. Откройте [страницу релизов](https://github.com/MineBotX/Dimasik-AI/releases).
2. Скачайте архив сборки Windows, если он доступен.
3. Распакуйте архив и запустите установщик из комплекта.

### Запуск из исходного кода

1. Установите Python 3.12.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/MineBotX/Dimasik-AI.git
   cd Dimasik-AI
   ```
3. Подготовьте окружение с помощью `setup.ps1` и установите зависимости из `requirements.txt`.
4. Запустите приложение командой, указанной в проекте для вашей сборки.

Для локального диалога и API требуется отдельно загрузить модель Granite через приложение. Первоначальная загрузка моделей требует интернет-соединения. После установки локальная генерация выполняется на компьютере; скорость зависит от процессора и оперативной памяти.

## Настройка

Основные пользовательские настройки находятся в `config.json`: слова активации, сайты, программы и стиль общения. Данные приложения и локальная история хранятся в папке `brain/`.

## Важно

- Проект находится в разработке. Возможности и качество ответов могут меняться.
- DimaCore 2.0 — экспериментальная компактная модель; для свободного диалога и API под конкретную задачу используется Granite.
- Сгенерированный код необходимо проверить самостоятельно. Димасик не запускает его автоматически.
- Локальный API не доступен другим компьютерам по умолчанию. Для удалённого доступа настройте VPN или защищённый HTTPS reverse proxy. Не открывайте порт API напрямую в интернет.
