# Димасик — локальный ИИ-помощник для Windows

**Димасик (DimasikAI)** — настольный голосовой и текстовый помощник. Он объединяет локальные языковые модели, голосовое управление, поиск в интернете и инструменты для повседневных задач.

## Возможности

- Текстовый чат и голосовое взаимодействие через графический интерфейс.
- Две локальные модели: экспериментальное компактное ядро DimaCore 2.0 и IBM Granite 4.2 3B.
- Автоматический выбор модели: короткие простые запросы направляются в DimaCore, длинные и сложные — в Granite. Если DimaCore не готов к работе, автоматический режим использует Granite.
- Распознавание русской речи через Vosk и озвучивание ответов.
- Чтение и анализ TXT, PDF, DOCX, XLSX, PPTX, JSON, CSV и других поддерживаемых файлов.
- Поиск в интернете и локальная история диалогов.
- Локальная генерация изображений с помощью Stable Diffusion.
- Заметки, задачи, напоминания и калькулятор.
- Голосовые команды для запуска программ и открытия сайтов.
- Дополнительные интеграции с GitHub и электронной почтой (при настройке).

## Модели ИИ

| Модель | Назначение |
|---|---|
| **DimaCore 2.0** | Экспериментальное компактное ядро для коротких и простых запросов |
| **IBM Granite 4.2 3B** | Сложные вопросы, анализ, программирование и развёрнутые ответы |
| **Авто** | Выбирает модель по длине запроса и ключевым словам |

Granite загружается отдельно через приложение. Для первой загрузки нужен интернет и около 2,24 ГБ свободного места плюс место для временного файла. После установки генерация выполняется локально.

## API для разработчиков

Встроенный API-генератор позволяет создать профиль для своей задачи. Локальный HTTP API совместим с форматом OpenAI Chat Completions.

- `GET /health` — проверка доступности сервера.
- `GET /v1/models` — список режимов (требуется ключ).
- `POST /v1/chat/completions` — генерация ответа (требуется ключ).

Поддерживаются режимы `auto`, `dimacore` и `granite`; `dimasik` и `all` — псевдонимы автоматического режима. Подробная инструкция на русском: [API.md](API.md).

По умолчанию API слушает только `127.0.0.1:8787`. Ключи показываются один раз и хранятся в базе только как SHA-256-хеши. Не публикуйте ключи и не встраивайте их в браузерный код.

## Тарифы и активация лицензии

В приложении есть три уровня доступа:

| Тариф | Возможности |
|---|---|
| **Free** | Базовый чат DimaCore и основные локальные инструменты |
| **Pro** | Всё из Free, Granite, написание кода и анализ документов |
| **Ultimate** | Всё из Pro, генерация изображений и локальный API |

Без файла лицензии приложение запускается в режиме Free. Чтобы включить платный тариф:

1. Администратор выпускает файл `.dimalic` в закрытом репозитории [DimasikAI-Licensing](https://github.com/MineBotX/DimasikAI-Licensing).
2. Публичный ключ `license_public.pem` из папки администратора нужно положить рядом с запускаемым приложением (в корень Dimasik).
3. В приложении откройте «Лицензия и тариф» → «Активировать .dimalic» и выберите полученный файл.
4. Для переноса на другой компьютер откройте то же окно, создайте `.dimareq` и передайте его администратору.

Проверка лицензии выполняется локально по подписи Ed25519, сроку действия и ID устройства. Приватный ключ подписи нельзя помещать в приложение или публиковать. Ограничение переноса раз в 7 дней хранится в единой базе администратора; без центрального сервера это правило действует только при обработке всех переносов через одну и ту же базу.

## Установка

### Windows

1. Откройте [страницу последнего релиза](https://github.com/MineBotX/Dimasik-AI/releases/tag/latest).
2. Скачайте архив `Dimasik-Windows-GUI-x64.zip`.
3. Распакуйте архив в отдельную папку.
4. Запустите `Install-Dimasik.bat` и следуйте инструкциям установщика.

### Запуск из исходного кода

1. Установите Python 3.12.
2. Склонируйте репозиторий:
   ```powershell
   git clone https://github.com/MineBotX/Dimasik-AI.git
   cd Dimasik-AI
   ```
3. Подготовьте окружение с помощью `setup.ps1` и установите зависимости из `requirements.txt`.

## Настройки и данные

Основные пользовательские настройки находятся в `config.json`. Локальные данные, история и служебные файлы API хранятся в папке `brain/`. Не удаляйте её, если хотите сохранить свои данные и ключи API.

## Безопасность и ограничения

- Проект находится в разработке; функции и качество ответов могут меняться.
- DimaCore 2.0 — экспериментальное ядро; его ответы могут быть менее точными, чем ответы Granite.
- Автоматический выбор модели основан на эвристиках длины и ключевых слов, а не на отдельной модели-оценщике.
- Сгенерированный код необходимо проверить самостоятельно. Димасик не запускает его автоматически.
- Локальный API по умолчанию доступен только на этом компьютере. Не открывайте порт API напрямую в интернет.
- Для удалённого доступа используйте защищённый VPN или HTTPS reverse proxy.
