# Димасик — локальный голосовой ИИ-помощник для Windows

**DimasikAI (Димасик)** — развиваемый голосовой помощник для Windows с собственным экспериментальным нейросетевым ядром **DimaCore 1.0**. Проект объединяет голосовое управление, обычный текстовый чат, команды Windows и дополнительные интеграции — без обязательной подписки и платных облачных ИИ API.

Главная особенность проекта — языковая модель **DimaCore 1.0** создана специально для Димасика на **Python и NumPy**. Это не Qwen, не Ollama и не подключённый ChatGPT. Модель и распознавание речи рассчитаны на локальную работу.

> **Важно:** проект находится в активной разработке. Собственная нейросеть пока небольшая и экспериментальная: она учится предсказывать следующий токен по короткому контексту и не сопоставима по возможностям с ChatGPT или крупными языковыми моделями. Поэтому ответы могут быть неточными или бессвязными. Мы открыто описываем текущее состояние, а не выдаём прототип за готовый искусственный интеллект общего назначения.

## Возможности

### Голосовой помощник
- Распознаёт русскую речь локально с помощью Vosk.
- Ожидает ключевое слово **«Димасик»** (также поддерживаются варианты из настроек).
- После активации принимает голосовую команду.
- Произносит ответы через голоса, установленные в Windows. Если в системе есть русский голос, приложение старается выбрать его автоматически.
- Позволяет включать и выключать микрофон отдельной кнопкой.
- Проверяет доступность устройства записи и показывает подсказки, если Windows не даёт использовать микрофон.

### Удобное окно приложения
- Чат для общения текстом, если не хочется говорить вслух.
- Отдельная большая кнопка включения микрофона и индикатор состояния.
- Аватар с эмоциями: радость, сочувствие, удивление, задумчивость и другие реакции.
- Для типичных бытовых реплик есть локальный диалоговый слой: приветствия, продолжение короткого разговора, благодарность, шутки и поддержка. Он использует недавние реплики, но не заменяет полноценную языковую модель.
- Озвучивание меняет темп речи в зависимости от эмоциональной окраски ответа; можно выбрать установленный русский голос через `voice_name` в `config.json` (часть `id` или имени голоса).
- Кнопка очистки текущего диалога.
- Раздел настроек и проверка обновлений прямо из приложения.

### Команды Windows
Димасик умеет выполнять ряд повседневных действий:
- открывать программы: например, Блокнот, Калькулятор, Проводник, Paint и Диспетчер задач;
- открывать пользовательские папки: Загрузки, Документы, Рабочий стол, Изображения, Музыка и Видео;
- запускать сайты из списка настроек и искать информацию в интернете через браузер;
- сообщать текущие дату и время;
- управлять системной громкостью и отключением звука;
- открывать настройки Windows, параметры экрана и звука;
- блокировать компьютер.

Список программ, сайтов и ключевых слов можно настраивать в `config.json`. Опасные команды удаления файлов, выключения и перезагрузки компьютера намеренно отключены.

### DimaCore 1.0 — собственная нейросеть
В Димасике используется **DimaCore 1.0** — экспериментальная языковая модель, реализованная на **NumPy**:
- учитывает до 12 предыдущих токенов;
- использует обучаемые векторные представления слов размерностью 48;
- содержит скрытый слой размерностью 192;
- обучается мини-пакетами с оптимизатором Adam, проверочной выборкой и ограничением градиентов;
- сохраняет лучшую версию параметров и словарь локально в папке `brain/`;
- проверяет размеры и значения весов при загрузке, безопасно отклоняя повреждённые или несовместимые файлы.

**DimaCore** обучается на примерах из `training_data.txt`. Текущие значения по умолчанию: окно контекста 12 токенов, эмбеддинги 48, скрытый слой 192, до 60 эпох с ранней остановкой. Обучение и генерация проходят численные проверки, но это всё ещё компактная экспериментальная модель: увеличение размеров само по себе не гарантирует умных ответов.

**Ограничения:** это компактная модель предсказания следующего токена с небольшим словарём и обучающим корпусом. Она не обладает полноценным пониманием мира, надёжной логикой, проверкой фактов или качеством больших языковых моделей. Параметры модели и локальная память — разные вещи: память хранит записи разговоров в SQLite и ищет похожие вопросы, но не меняет веса нейросети.


### Создание программного кода

Димасик распознаёт просьбы написать программу и использует отдельный локальный модуль `assistant/code_writer.py`. Код не пытается сочинять маленькая нейросеть DimaCore: для поддерживаемых задач используются проверенные заготовки, а Python-код перед показом дополнительно проверяется синтаксическим анализатором. Сгенерированный код не запускается автоматически.

В первой версии есть заготовки:
- Python: консольный калькулятор, игра «Угадай число», список задач с сохранением JSON и простой локальный JSON API;
- HTML: адаптивная стартовая веб-страница;
- JavaScript, C++ и Java: калькуляторы.

Например, напиши в чате или скажи голосом: «Напиши код калькулятора на Python». Димасик покажет исходный код в чате и не будет зачитывать его вслух.

Это первый офлайн-этап, а не универсальный генератор любых программ. Для нестандартного проекта Димасик попросит уточнить язык, поведение и входные/выходные данные. Код из заготовки нужно проверить и запустить самостоятельно.

### Интернет-поиск и локальная память
- Вопросы автоматически отправляются в поиск DuckDuckGo, если доступен интернет.
- Димасик показывает заголовки, выдержки и прямые ссылки на найденные страницы.
- Если поиск не сработал, он пытается найти похожие вопросы и ответы в локальной базе SQLite.
- История хранится в файле `brain/knowledge.sqlite3` на компьютере пользователя.
- Локальные записи не являются проверенными фактами: при отсутствии сети Димасик предупреждает об этом.
- Результаты поисковой выдачи — только краткие выдержки. Для важных решений нужно открыть страницы и проверить первоисточники.
- Димасик не использует разговоры других пользователей. Общая база возможна только из данных, предоставленных с разрешением и проверенных отдельно.

### API генерации игровых прицелов

При запуске Димасика автоматически включается локальный API для создания геометрических игровых прицелов по текстовому описанию. Он не требует платного сервиса, ключа API или подключения к интернету.

- Адрес: `http://127.0.0.1:8765` (доступен только на этом компьютере).
- `GET /health` — проверка работы.
- `POST /generate-crosshair` — генерация изображения. JSON: `{"description":"маленький зелёный прицел-крестик с чёрной обводкой","format":"png"}`.
- Формат по умолчанию — PNG 512×512 с прозрачным фоном. Можно указать `"format":"svg"`.
- Распознаются основные цвета (зелёный, красный, голубой, синий, жёлтый, белый и другие), крестик, точка, круг и четыре точки, а также простые указания размера, толщины и обводки.

Пример на Python:

```python
import requests

response = requests.post(
    "http://127.0.0.1:8765/generate-crosshair",
    json={
        "description": "маленький зелёный крестик с чёрной обводкой",
        "format": "png",
    },
    timeout=15,
)
response.raise_for_status()
with open("my_crosshair.png", "wb") as file:
    file.write(response.content)
```

API использует правила разбора описания и рисует векторную геометрию, а не генерирует художественную картинку нейросетью. Это локальная первая версия: сложные или неоднозначные описания могут интерпретироваться упрощённо. Сервер намеренно привязан к `127.0.0.1` и не открыт в локальную сеть.

### Интеграции
- **GitHub:** отдельное окно подключения, просмотр списка репозиториев и безопасное хранение токена в системном хранилище Windows. Внутренний модуль также поддерживает чтение файлов репозитория, создание веток, запись изменений в отдельную ветку и создание Pull Request; полноценный редактор этих операций в графическом интерфейсе ещё не реализован. Запись напрямую в `main` и `master` запрещена модулем.
- **Электронная почта:** настройка IMAP/SMTP, просмотр последних писем и защищённое хранение пароля приложения в Windows. Внутренний модуль поддерживает отправку писем, но отдельного интерфейса написания и отправки писем, автоматических ответов и автономной автоотправки пока нет.

Подключения GitHub и почты необязательны. Для них нужны собственные учётные данные и разрешения соответствующего сервиса.

## Установка готовой версии Windows

1. Открой [страницу последнего релиза](https://github.com/MineBotX/Dimasik-AI/releases/tag/latest).
2. Скачай архив **Dimasik-Windows-GUI-x64.zip**.
3. Распакуй архив полностью в отдельную папку.
4. Запусти **Install-Dimasik.bat** и следуй подсказкам установщика.

**Устанавливать Python вручную не требуется.** Готовая сборка включает приложение и необходимые компоненты, в том числе модель Vosk для распознавания русской речи.

Интернет может понадобиться для скачивания архива, установки компонентов, проверки обновлений, поиска в браузере и работы подключённых онлайн-сервисов. Основное распознавание речи и локальная работа нейросетевого ядра не требуют платного облачного ИИ API.

## Обучение собственной модели из исходного кода

Для разработки понадобится Python 3.12.

1. Склонируй репозиторий или скачай исходный код.
2. Запусти `setup.ps1`, чтобы подготовить окружение и установить зависимости.
3. Обучающие примеры хранятся в `training_data.txt` — по одному примеру на строку. В репозитории есть расширенный базовый русский набор.
4. Запусти обучение:

   ```bash
   python train_brain.py
   ```

5. После успешного обучения запусти приложение снова.

Для заметного улучшения качества нужны большие, разнообразные и хорошо подготовленные обучающие данные, развитие архитектуры и регулярные проверки качества. Простое добавление нескольких фраз не превращает небольшую модель в универсального помощника.

## Технологии

- **Python** — приложение и обучение модели.
- **NumPy** — собственная нейросеть и алгоритм обучения.
- **Vosk** — локальное распознавание речи.
- **pyttsx3** — озвучивание через голоса Windows.
- **Tkinter** — графический интерфейс.
- **sounddevice** — работа с микрофоном.
- **PyInstaller** — сборка Windows-приложения.
- **keyring** — хранение токенов и паролей в системном хранилище учётных данных.

## Что планируется

- Более связный контекст диалога и управляемая долговременная память.
- Развитие архитектуры собственной языковой модели и расширение обучающего корпуса.
- Удобное редактирование файлов GitHub с просмотром изменений до отправки.
- Интерфейс создания черновиков и отправки писем с подтверждением пользователя.
- Больше голосовых команд и безопасных действий в Windows.
- Улучшение интерфейса, диагностики, тестирования и установки.

Это направления развития, а не функции, которые уже полностью доступны в текущей версии.

## Принципы DimasikAI

- **Локальность:** основные голосовые функции и собственная модель работают на компьютере.
- **Независимость:** нет обязательной привязки к платным ИИ API.
- **Открытость:** исходный код можно изучать, менять и развивать.
- **Безопасность:** чувствительные данные интеграций хранятся отдельно от обычного файла настроек; опасные команды ограничены.
- **Честность:** возможности прототипа и планы разработки не смешиваются.
