# Димасик — локальный голосовой помощник для Windows

## Установка
1. Скачай новый Install_Dimasik.bat из репозитория.
2. Запусти его двойным щелчком.
3. Дождись установки Python, библиотек, Vosk, Ollama и Qwen.
4. Запусти ярлык «Димасик» на рабочем столе.

Установщик сохраняет твой config.json при обновлении. Интернет нужен для первоначальной загрузки компонентов и моделей. После установки распознавание речи и ответы ИИ работают локально.

## Команды
- «Димасик, сколько времени?» / «какая дата?»
- «Открой блокнот / калькулятор / проводник / Paint / диспетчер задач».
- «Открой загрузки / документы / рабочий стол / изображения / музыку / видео».
- «Открой YouTube / Google / почту / диск / GitHub».
- «Громче», «тише», «выключи звук».
- «Открой настройки Windows», «параметры экрана», «параметры звука».
- «Заблокируй компьютер».
- «Найди ...», «помощь», «очисти диалог».

## Кастомизация
Файл настроек: %LOCALAPPDATA%\Dimasik\config.json. Его можно открыть Блокнотом. Поддерживаются имя помощника, ключевые слова, скорость и громкость речи, характер ответов, модель Ollama, список приложений и сайтов. После изменения перезапусти помощника.

Пример JSON:
{
  "assistant_name": "Димасик",
  "wake_words": ["димасик", "джарвис"],
  "voice_rate": 172,
  "voice_volume": 1.0,
  "personality": "Вежливый помощник в стиле Джарвиса"
}

## Требования и ограничения
- Windows 10/11, микрофон и динамики.
- Рекомендуется 8 ГБ ОЗУ или больше.
- Мужской голос зависит от голосов, установленных в Windows.
- Помощник не исполняет произвольные команды PowerShell и не удаляет файлы.
- Это локальная начальная версия, а не полный аналог киношного JARVIS.
