# Димасик — офлайн голосовой помощник для Windows

Димасик — локальный русскоязычный помощник для Windows 10/11.

## Что умеет
- Активация голосом: «Димасик».
- Офлайн-распознавание речи через Vosk.
- Ответы локальной модели Qwen 2.5 3B через Ollama.
- Озвучивание через установленные голоса Windows.
- Помнит контекст текущего диалога, пока программа запущена.
- Открывает Блокнот, Калькулятор, Проводник, Paint и Диспетчер задач.
- Сообщает дату и время.
- Ищет информацию в браузере по команде «Димасик, найди ...».

## Установка
1. Скачай `Install_Dimasik.bat` из корня репозитория.
2. Запусти файл на Windows 10/11.
3. Дождись установки Python, библиотек, Vosk, Ollama и модели Qwen.
4. Запусти ярлык «Димасик» на рабочем столе.

Во время установки нужен интернет. После установки распознавание и генерация ответов выполняются локально. Рекомендуется от 8 ГБ ОЗУ; на слабом ПК ответы могут быть медленными.

## Голос
Программа пытается выбрать установленный русский голос Windows. Мужской тембр не гарантируется: это зависит от доступных системных голосов. Дополнительные голоса можно установить в настройках Windows: Время и язык → Речь.

## Безопасность и ограничения
Димасик не выполняет произвольные команды PowerShell, не удаляет файлы и не выключает компьютер по голосовой команде. История диалога хранится только в оперативной памяти и очищается после закрытия программы.

Это развиваемая начальная версия, не полный аналог киношного JARVIS.
