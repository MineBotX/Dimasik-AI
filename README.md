# Димасик — локальный голосовой ИИ-помощник для Windows

**DimasikAI (Димасик)** — локальный голосовой помощник для Windows. Он объединяет управление голосом и текстом, локальный диалог и генерацию кода через **IBM Granite 4.2 3B**, экспериментальное нейросетевое ядро **DimaCore 1.0**, поиск в интернете, создание изображений, анализ документов и личные инструменты для заметок, задач и напоминаний. Можно настраивать слова активации, характер общения, сайты и запускаемые программы — без обязательной подписки и платных облачных ИИ API.

В проекте есть собственное экспериментальное нейросетевое ядро **DimaCore 1.0**, реализованное на **Python и NumPy**. Для свободного диалога, ответов на вопросы, анализа документов и генерации кода дополнительно используется локальная модель **IBM Granite 4.2 3B** через llama.cpp. Это две разные модели: DimaCore — собственная компактная разработка проекта, а Granite — предварительно обученная модель, которую пользователь загружает отдельно. После установки они работают на компьютере пользователя без платного облачного ИИ API.

> **Важно:** проект находится в активной разработке. Собственная нейросеть пока небольшая и экспериментальная: она учится предсказывать следующий токен по короткому контексту и не сопоставима по возможностям с ChatGPT или крупными языковыми моделями. Поэтому ответы могут быть неточными или бессвязными. Мы открыто описываем текущее состояние, а не выдаём прототип за готовый искусственный интеллект общего назначения.

## Возможности

### Голосовой помощник
- Распознаёт русскую речь локально с помощью Vosk.
- По умолчанию реагирует на слова **«Димасик»**, **«Димас»**, **«Димка»** и **«Димон»**. Список слов активации меняется в `config.json`.
- После активации принимает голосовую команду.
- Произносит ответы через голоса, установленные в Windows. Если в системе есть русский голос, приложение старается выбрать его автоматически.
- Позволяет включать и выключать микрофон отдельной кнопкой.
- Проверяет доступность устройства записи и показывает подсказки, если Windows не даёт использовать микрофон.

### Удобное окно приложения
- Обновлённая тёмная тема с карточками, плавными скруглёнными углами и кнопками с подсветкой при наведении.
- Поле ввода, панель чата и основные действия собраны в отдельные аккуратные блоки с увеличенными отступами.
- Чат для общения текстом, если не хочется говорить вслух.
- Отдельная большая кнопка включения микрофона и индикатор состояния.
- Аватар с эмоциями: радость, сочувствие, удивление, задумчивость и другие реакции.
- Для типичных бытовых реплик есть локальный диалоговый слой: приветствия, продолжение короткого разговора, благодарность, шутки и поддержка. Он использует недавние реплики, но не заменяет полноценную языковую модель.
- Озвучивание меняет темп речи в зависимости от эмоциональной окраски ответа; можно выбрать установленный русский голос через `voice_name` в `config.json` (часть `id` или имени голоса).
- Кнопка очистки текущего диалога.
- Раздел настроек и проверка обновлений прямо из приложения.

### Команды Windows
Димасик умеет выполнять ряд повседневных действий:
- открывать программы: например, Блокнот, Калькулятор, Проводник, Paint, Диспетчер задач и Google Chrome (команда «открой браузер»);
- открывать пользовательские папки: Загрузки, Документы, Рабочий стол, Изображения, Музыка и Видео;
- запускать сайты из списка настроек: YouTube, Google, Gmail, Google Диск, GitHub и MAX; например, «открой ютуб» или «открой гит хаб»;
- сообщать текущие дату и время;
- управлять системной громкостью и отключением звука;
- открывать настройки Windows, параметры экрана и звука;
- блокировать компьютер.

Список программ, сайтов, слов активации и характер общения можно настраивать в `config.json`. Названия команд нормализуются по регистру: например, ключ «Браузер» распознаётся так же, как «браузер». Для запуска Chrome используется `chrome.exe`; если Windows не находит его, укажи полный путь к `chrome.exe` в настройках. Опасные команды удаления файлов, выключения и перезагрузки компьютера намеренно отключены.

### DimaCore 1.0 — собственная экспериментальная нейросеть

DimaCore — отдельное компактное ядро проекта. Для полноценного свободного диалога, ответов на вопросы и написания кода Димасик использует дополнительно устанавливаемую локальную модель Granite; эти две модели не следует путать.
В Димасике используется **DimaCore 1.0** — экспериментальная языковая модель, реализованная на **NumPy**:
- учитывает до 12 предыдущих токенов;
- использует обучаемые векторные представления слов размерностью 48;
- содержит скрытый слой размерностью 192;
- обучается мини-пакетами с оптимизатором Adam, проверочной выборкой и ограничением градиентов;
- сохраняет лучшую версию параметров и словарь локально в папке `brain/`;
- проверяет размеры и значения весов при загрузке, безопасно отклоняя повреждённые или несовместимые файлы.

**DimaCore** обучается на примерах из `training_data.txt`. Текущие значения по умолчанию: окно контекста 12 токенов, эмбеддинги 48, скрытый слой 192, до 60 эпох с ранней остановкой. Обучение и генерация проходят численные проверки, но это всё ещё компактная экспериментальная модель: увеличение размеров само по себе не гарантирует умных ответов.

**Ограничения:** это компактная модель предсказания следующего токена с небольшим словарём и обучающим корпусом. Она не обладает полноценным пониманием мира, надёжной логикой, проверкой фактов или качеством больших языковых моделей. Параметры модели и локальная память — разные вещи: память хранит записи разговоров в SQLite и ищет похожие вопросы, но не меняет веса нейросети.


### Самостоятельное написание программного кода

Для свободного общения, объяснений, анализа документов и создания произвольного нового кода Димасик использует локальную языковую модель **IBM Granite 4.2 3B** в формате GGUF Q4_K_M. Генерация выполняется на компьютере через официальный CPU-движок llama.cpp. Это не шаблоны и не попытка заставить маленькую DimaCore угадывать ответы по токенам.

Первый запуск:
1. Установи свежую сборку Димасика, в комплект которой включён CPU-движок llama.cpp.
2. Нажми в окне Димасика кнопку **«Модель ИИ»**.
3. Дождись загрузки модели Granite (примерно 2,24 ГБ). Приложение проверит SHA-256 перед установкой.
4. После этого можно общаться, задавать вопросы, просить объяснения, анализировать документы и писать программы.

Модель работает локально, без платного API и без Qwen/Ollama. Интернет нужен для первоначальной загрузки весов и для онлайн-поиска; сам диалог и генерация кода затем выполняются на CPU без облачного ИИ. Скорость зависит от процессора и доступной оперативной памяти. Для модели потребуется около 3 ГБ свободного места на диске и дополнительная RAM для запуска.

**Важно о слове «обучение»:** Granite — уже предварительно обученная модель, умеющая работать с кодом. В текущей версии Димасик подключает её для локальной генерации; мы не проводим полное дообучение миллиардов параметров на компьютере пользователя. DimaCore остаётся отдельной маленькой экспериментальной нейросетью для простых диалогов.

Димасик не исполняет сгенерированный код автоматически. Результат нужно просмотреть, сохранить и проверить перед использованием. Модель может ошибаться, особенно в больших или сложных проектах.

### Интернет-поиск и локальная память
- Вопросы и явные команды поиска отправляются в бесплатные публичные поисковые системы DuckDuckGo и Bing; если первая система не отвечает или меняет разметку, Димасик пробует резервный поисковик.
- В чате можно написать: «Найди ...», «Поищи ...» или «Загугли ...». Голосовые команды поиска используют тот же механизм.
- Димасик показывает заголовки, выдержки и прямые ссылки на найденные страницы.
- Если поисковые системы недоступны, Димасик показывает причину сбоя и ссылку для открытия поиска вручную.
- Если онлайн-поиск не сработал, он пытается найти похожие вопросы и ответы в локальной базе SQLite.
- История хранится в файле `brain/knowledge.sqlite3` на компьютере пользователя.
- Локальные записи не являются проверенными фактами: при отсутствии сети Димасик предупреждает об этом.
- Результаты поисковой выдачи — только краткие выдержки. Для важных решений нужно открыть страницы и проверить первоисточники.
- Димасик не использует разговоры других пользователей. Общая база возможна только из данных, предоставленных с разрешением и проверенных отдельно.

### Локальная генерация изображений

Димасик умеет создавать PNG-картинки по текстовому описанию полностью на компьютере пользователя.

Первоначальная установка:
1. Запусти новую сборку приложения.
2. Нажми кнопку **«🖼 Модель картинок»** и подтверди загрузку.
3. Дождись загрузки Stable Diffusion 1.5 Q4_0 (около 1,75 ГБ). Димасик проверит размер файла и SHA-256.
4. Нажми **«🖼 Создать картинку»** или напиши в чате, например: «Нарисуй уютную кофейню в дождливом городе».

Изображения создаются локально с помощью **stable-diffusion.cpp**. В комплект Windows включены две версии движка — Vulkan и CPU. Димасик проверяет доступность Vulkan-устройства, выбирает GPU, если он поддерживается, а при его отсутствии или ошибке переключается на отдельную CPU-сборку. Скорость и возможность запуска зависят от оборудования и драйверов; CPU-генерация может занимать много времени. Для комфортного запуска рекомендуется не менее 8 ГБ оперативной памяти. Стандартный результат — PNG 512×512, 20 шагов.

Готовые файлы сохраняются в папку `generated_images` рядом с приложением. Предпросмотр появляется прямо в чате; нажатие на него открывает оригинал.

После первоначальной загрузки модели генерация не обращается к облачным сервисам и не требует платного API. Для установки модели нужен интернет; далее можно отключить сеть. Используемые веса Stable Diffusion 1.5 Q4_0 распространяются по лицензии **CreativeML OpenRAIL-M** — она содержит условия допустимого использования. Перед распространением или коммерческим использованием созданных материалов ознакомься с условиями лицензии и правами на результаты.

### Диалог, работа с документами и личная продуктивность

После установки Granite обычный диалог, ответы на вопросы, объяснения, помощь с учёбой, идеи, редактирование текста и программирование работают через одну локальную модель. При наличии интернета Димасик может искать источники, а Granite — составлять по ним краткий ответ. Если поиск не сработал, он предупреждает, что ответ не проверен в сети.

Кнопка **«Файл»** позволяет прикрепить документ для локального анализа. Поддерживаются TXT, Markdown, исходный код, JSON, CSV, HTML, XML, PDF, Word DOCX, Excel XLSX и PowerPoint PPTX. Максимальный размер исходного файла — 25 МБ; в модель передаётся не более 18 000 символов извлечённого текста. Для сканированного PDF без текстового слоя потребуется отдельное распознавание OCR, которого пока нет. Код из файлов не запускается.

Встроенные личные инструменты:
- **Заметки:** «запомни заметку купить продукты», «покажи заметки», «удали заметку 2».
- **Задачи:** «добавь задачу проверить проект», «покажи задачи», «выполнил задачу 3».
- **Напоминания:** «напомни через 15 минут проверить чайник», «напомни в 18:30 позвонить», «покажи напоминания».
- **Калькулятор:** «посчитай (25 + 5) * 3». Вычислитель допускает только арифметические операции и не исполняет Python-код.
- Кнопка **«Мои дела»** открывает сохранённые заметки, задачи и напоминания.

Заметки, задачи и напоминания хранятся локально в `brain/productivity.sqlite3`. Напоминания проверяются, пока Димасик запущен; если время наступило при закрытом приложении, уведомление появится после следующего запуска. Это не системная служба и не гарантия уведомления, когда Windows выключена.

### API генерации игровых прицелов

При запуске Димасика автоматически включается локальный API для создания геометрических игровых прицелов по текстовому описанию. Он не требует платного сервиса, ключа API или подключения к интернету.

- Адрес: `http://127.0.0.1:8765` (доступен только на этом компьютере).
- `GET /health` — проверка работы.
- `POST /generate-crosshair` — генерация изображения. JSON: `{"description":"маленький зелёный прицел-крестик с чёрной обводкой","format":"png"}`.
- Формат по умолчанию — PNG 512×512 с прозрачным фоном. Можно указать `"format":"svg"`.
- Распознаются основные цвета (зелёный, красный, голубой, синий, жёлтый, белый и другие), крестик, точка, круг и четыре точки, а также простые указания размера, толщины и обводки.

Пример на Python:

```python
import requests

response = requests.post(
    "http://127.0.0.1:8765/generate-crosshair",
    json={
        "description": "маленький зелёный крестик с чёрной обводкой",
        "format": "png",
    },
    timeout=15,
)
response.raise_for_status()
with open("my_crosshair.png", "wb") as file:
    file.write(response.content)
```

API использует правила разбора описания и рисует векторную геометрию, а не генерирует художественную картинку нейросетью. Это локальная первая версия: сложные или неоднозначные описания могут интерпретироваться упрощённо. Сервер намеренно привязан к `127.0.0.1` и не открыт в локальную сеть.

### Интеграции
- **GitHub:** отдельное окно подключения, просмотр списка репозиториев и безопасное хранение токена в системном хранилище Windows. Внутренний модуль также поддерживает чтение файлов репозитория, создание веток, запись изменений в отдельную ветку и создание Pull Request; полноценный редактор этих операций в графическом интерфейсе ещё не реализован. Запись напрямую в `main` и `master` запрещена модулем.
- **Электронная почта:** настройка IMAP/SMTP, просмотр последних писем, создание и отправка письма через отдельное окно с обязательным подтверждением. Пароль приложения хранится в защищённом хранилище Windows.

Подключения GitHub и почты необязательны. Для них нужны собственные учётные данные и разрешения соответствующего сервиса.

## Настройка команд и характера общения

Настройки хранятся в файле `config.json` рядом с приложением. В стандартном наборе доступны следующие примеры голосовых команд:

| Что сказать | Что делает |
|---|---|
| «Димка, открой браузер» | Запускает `chrome.exe` |
| «Димасик, открой макс» | Открывает MAX в браузере |
| «Димас, открой гит хаб» | Открывает GitHub |
| «Димон, открой ютуб» | Открывает YouTube |

Слова активации задаются в массиве `wake_words`, программы — в разделе `apps`, сайты — в `websites`, характер и стиль ответов локальной модели — в `personality`. Изменения в уже существующем пользовательском `config.json` имеют приоритет над встроенными значениями по умолчанию.

Пример отдельных записей:

```json
{
  "wake_words": ["димасик", "димас", "димка", "димон"],
  "personality": "Дружелюбный, креативный, умный. Отвечай по-русски и обычно кратко.",
  "websites": {
    "макс": "https://web.max.ru",
    "гит хаб": "https://github.com"
  },
  "apps": {
    "браузер": ["chrome.exe"]
  }
}
```

## Установка готовой версии Windows

1. Открой [страницу последнего релиза](https://github.com/MineBotX/Dimasik-AI/releases/tag/latest).
2. Скачай архив **Dimasik-Windows-GUI-x64.zip**.
3. Распакуй архив полностью в отдельную папку.
4. Запусти **Install-Dimasik.bat** и следуй подсказкам установщика.

**Устанавливать Python вручную не требуется.** Готовая сборка включает приложение и необходимые компоненты, в том числе модель Vosk для распознавания русской речи.

Интернет может понадобиться для скачивания архива, установки компонентов, проверки обновлений, поиска в браузере и работы подключённых онлайн-сервисов. Основное распознавание речи и локальная работа нейросетевого ядра не требуют платного облачного ИИ API.

## Обучение собственной модели из исходного кода

Для разработки понадобится Python 3.12.

1. Склонируй репозиторий или скачай исходный код.
2. Запусти `setup.ps1`, чтобы подготовить окружение и установить зависимости.
3. Обучающие примеры хранятся в `training_data.txt` — по одному примеру на строку. В репозитории есть расширенный базовый русский набор.
4. Запусти обучение:

   ```bash
   python train_brain.py
   ```

5. После успешного обучения запусти приложение снова.

Для заметного улучшения качества нужны большие, разнообразные и хорошо подготовленные обучающие данные, развитие архитектуры и регулярные проверки качества. Простое добавление нескольких фраз не превращает небольшую модель в универсального помощника.

- **pyttsx3** — озвучивание через голоса Windows.
- **Tkinter** — графический интерфейс.
- **sounddevice** — работа с микрофоном.

## Что планируется

- Более связный контекст диалога и управляемая долговременная память.
- Развитие архитектуры собственной языковой модели и расширение обучающего корпуса.
- Удобное редактирование файлов GitHub с просмотром изменений до отправки.
- Интерфейс создания черновиков и отправки писем с подтверждением пользователя.
- Больше голосовых команд и безопасных действий в Windows.
- Улучшение интерфейса, диагностики, тестирования и установки.

Это направления развития, а не функции, которые уже полностью доступны в текущей версии.

## Принципы DimasikAI

- **Локальность:** основные голосовые функции и собственная модель работают на компьютере.
- **Независимость:** нет обязательной привязки к платным ИИ API.
- **Открытость:** исходный код можно изучать, менять и развивать.
- **Безопасность:** чувствительные данные интеграций хранятся отдельно от обычного файла настроек; опасные команды ограничены.
- **Честность:** возможности прототипа и планы разработки не смешиваются.
