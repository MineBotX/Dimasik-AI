# Димасик — локальный голосовой ИИ-помощник для Windows

**Димасик** — экспериментальный проект персонального голосового помощника для Windows. Его главная идея — собственное нейросетевое ядро, которое можно обучать и развивать, не подключая платные облачные ИИ-сервисы.

Проект создаётся как локальный помощник: распознаёт русскую речь, отвечает голосом Windows и выполняет ряд полезных действий на компьютере. Нейросеть написана специально для проекта на Python и NumPy — это не Qwen, не Ollama и не подключение к ChatGPT.

> **Важно:** Димасик пока находится на ранней экспериментальной стадии. Его нейросеть — небольшая языковая модель для предсказания следующего слова, а не полноценная система уровня ChatGPT. Качество ответов зависит от обучающих данных и пока ограничено.

## Что умеет

- Распознавать русскую речь с помощью локальной модели Vosk.
- Произносить ответы через установленные голоса Windows.
- Открывать программы, папки и сайты.
- Выполнять отдельные команды Windows: управлять громкостью, открывать системные настройки и блокировать компьютер.
- Работать с собственным локальным нейросетевым ядром.
- Обучать нейросеть на дополнительных текстах.
- Проверять наличие обновлений приложения.

Набор команд и возможностей будет расширяться по мере разработки.

## Собственная нейросеть

В проекте используется небольшая нейронная сеть, реализованная на **NumPy**.

Текущая экспериментальная архитектура:
- учитывает контекст до 8 предыдущих токенов;
- использует обучаемые векторные представления слов размерностью 32;
- содержит полносвязный скрытый слой размерностью 128;
- обучается мини-пакетами с помощью оптимизатора Adam;
- сохраняет обученные параметры локально в `brain/dimasik_brain.npz`.

Модель обучается на текстах из `training_data.txt`. Можно добавлять собственные примеры и запускать обучение повторно.

**Честно о текущем уровне:** это ранняя контекстная языковая модель с небольшим словарём и обучающим набором. Она может генерировать продолжение текста, но пока не обладает глубоким пониманием смысла, надёжными рассуждениями или возможностями больших языковых моделей. Увеличение числа слоёв само по себе этого не исправит — нужны качественные данные, подходящая архитектура и тестирование.

## Установка готовой версии

1. Открой страницу [последнего релиза](https://github.com/MineBotX/Dimasik-AI/releases/tag/latest).
2. Скачай архив **Dimasik-Windows-GUI-x64.zip**.
3. Полностью распакуй архив в отдельную папку.
4. Запусти **Install-Dimasik.bat** и следуй инструкциям.

Python вручную устанавливать не требуется: готовая Windows-сборка включает необходимые компоненты приложения и модель распознавания русской речи Vosk.

Для скачивания архива и установки компонентов может потребоваться интернет. После установки основные функции распознавания, озвучивания и локальной генерации рассчитаны на работу без облачных ИИ API.

## Обучение из исходного кода

Понадобится Python 3.12.

1. Склонируй репозиторий или скачай его архив.
2. Запусти `setup.ps1` для подготовки окружения и установки зависимостей.
3. Добавляй обучающие примеры в `training_data.txt` — по одному тексту на строку.
4. Запусти команду:

   ```bash
   python train_brain.py
   ```

5. После обучения запусти приложение снова.

Обучающие примеры должны быть грамотными, разнообразными и соответствовать предполагаемым задачам помощника. Небольшой набор однотипных фраз не даст модели широких знаний.

## Технологии

- **Python** — логика приложения и обучение.
- **NumPy** — реализация и обучение нейросетевого ядра.
- **Vosk** — локальное распознавание речи.
- **pyttsx3** — озвучивание через доступные голоса Windows.
- **PyInstaller** — сборка Windows-приложения.
